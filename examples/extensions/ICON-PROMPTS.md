# Example extension icons

Generated with the built-in imagegen tool. The transparent PNG outputs were resized to 192×192 with alpha preserved and saved as `comet-essentials/icon.png` and `comet-portfolio/icon.png`. Both files are below the 64 KiB icon limit and are included in the corresponding example ZIPs.

## Comet Essentials prompt

Use case: logo-brand. Create one polished square extension icon for Comet Essentials, a reusable website building-block toolkit. A compact geometric cluster of three interlocking modular blocks forming a subtle upward spark/comet silhouette, teal and emerald with a small warm yellow accent. Clean friendly dimensional illustration, crisp bold silhouette, restrained soft shading, generous clear padding, no letters, no words, no watermark, no frame or background tile. Actual transparent background. Must read clearly at 48 by 48 pixels. This will be a PNG icon for a CMS extension list.

## Comet Portfolio prompt

Use case: logo-brand. Create one polished square extension icon for Comet Portfolio, a showcase of projects and creative work. A compact upright open portfolio case with two overlapping project cards, the front card showing a simple mountain-and-sun artwork symbol. Rich indigo and violet with a small coral accent. Clean friendly dimensional illustration, crisp bold silhouette, restrained soft shading, generous clear padding, no letters, no words, no watermark, no frame or background tile. Actual transparent background. Must read clearly at 48 by 48 pixels. This will be a PNG icon for a CMS extension list, paired with a teal modular-block toolkit icon in the same restrained dimensional style.
